About

A tiny tool that treats a word like a prop.

MatchCutter started with a simple observation: a single word, held still while its context flickers, feels louder than a paragraph. Newspaper clippings are perfect for this — heavy ink, rough paper, a little skew. The match cut does the rest.

The whole thing runs in your tab. There is no server, no database, no account. The code is Vite + TypeScript, Canvas2D for rendering, WebCodecs + mp4-muxer (MIT) for MP4, MediaRecorder for WebM, Web Audio for sound. Fonts are OFL (Playfair, Libre Baskerville, Old Standard, Special Elite, IM Fell, Courier Prime) and paper is noise, not images. You can view source, read the procedural grain, and know exactly what runs.

Editorial intent

We wanted a tool that feels like a desk, not a dashboard. Warm paper, charcoal ink, a serif display, generous margins, no neon. If a control doesn’t need to be there, it isn’t. Dark mode follows your system preference.

No tracking, by design

No analytics, no cookies, no pixel. The SupportGate module exists but is disabled — it never renders, never fetches, never measures. If the maintainer ever enables it, it will be a visible placeholder, not a tracker. See Privacy.
